# Ahjo

The words Ahjo uses, for all three apps: Swarm, Brain and Desk. One word means
one thing, everywhere: in a command, in a saved file and on the screen. Words
under _Avoid_ are old names; do not use them.

## Missions

**Mission**:
A plan of work for agents: steps, gates, limits and ends, saved as one file.
_Avoid_: board, flow

**Card**:
Anything on a mission's board: an input, a step, a gate, a limit or an end.
_Avoid_: node

**Step**:
One piece of a mission's work. Agents sitting in its seats do it.
_Avoid_: formation (for the step itself), node

**Seat**:
A place in a step where one agent sits, with a harness, a model and an effort.
_Avoid_: slot

**Formation**:
How a step's seats work together: one agent alone (solo), agents side by side
(peer), or one agent leading others (orchestrated).
_Avoid_: type

**Gate**:
A check between steps that passes or fails what a step made, or picks the
best of what several steps made side by side. You, a judge agent or a code
check decides; only you or a judge can pick.

**Run**:
One time a mission is carried out.

**Attempt**:
One try at a step within a run. A step that fails its gate can try again.

**Reason**:
The words you give when you approve, pick, stop or resume something.
_Avoid_: response

## Agents and where they run

**Agent**:
A named setup you can reuse: its instructions, harness, model and effort, and
notes on how it has done.
_Avoid_: role, character

**Harness**:
The program an agent runs in, such as Claude Code or Codex, and the files in
a folder that shape it.

**Session**:
A tmux session. During a run, a seat's agent works in one.
_Avoid_: session stem

**Node**:
A machine running Ahjo. Nothing else is called a node.
_Avoid_: device

**Environment**:
Where a step runs.
_Avoid_: device, place, home

## Work

**Issue**:
A Beads or GitHub issue: something to be done. A step works on one; the
Issues page lists them.
_Avoid_: work, work item, task

**Scheduled prompt**:
A prompt sent into sessions on a timer.
_Avoid_: task (on its own)

## On screen

**Panel**:
The one column at the edge of the window. What a page opens next to itself
stands there.
_Avoid_: dock, drawer, side panel, edge panel, beside view

**Side section**:
A page's part of the left column, which is on every page. Sessions' list is
one, shown on every page.
_Avoid_: side panel

**Popup**:
A small menu, question or form that opens next to what you clicked and closes
with Escape.
_Avoid_: popover

**Layer**:
Something that covers the whole page or window for a moment, such as Overview,
Peek or a rename, and closes with Escape.
_Avoid_: overlay

**Peek**:
A session's terminal laid over the page, usable as in its own window.

**Overview**:
A layer showing every session as a card with its screen.

**Beside**:
Next to something without covering it.

**Web page**:
A `.html` file in Files, shown running rather than as text, with its source a
switch away. It loads only from the folder it was opened in.
_Avoid_: preview, prototype view

**Send**:
Send to Session: handing a reference and a note to one or more sessions, from
the panel.
_Avoid_: drawer, Send drawer
